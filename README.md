# JankyFantasy

Local co-op brawler made in Unity (school project, May–June 2026).
1 to 4 players pick a class (Paladin, Mage, Archer), combine elemental attacks
to trigger combos, and revive downed teammates to beat a boss.

**Scripts only.** The full Unity project isn't public because of third-party assets.
Gameplay video: https://shadow-raphaelc.github.io/projects/jankyfantasy.html

## My part
- Combat base class (`Combattant`) and player character subclass
- 3 playable classes with passive and held perks
- Revive system
- Elemental combo system (`ElementMark`, `ElementCombo`)
- Local multiplayer input: up to 4 players on 2 keyboard layouts and gamepads
